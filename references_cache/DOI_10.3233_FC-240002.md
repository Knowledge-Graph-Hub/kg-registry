# Advancements in EcoPortal: Enhancing functionalities for the ecological domain semantic artefacts repository
**Authors:** Andrea Tarallo, Martina Pulieri, Parham Ramezani, Ilaria Rosati
**Journal:** FAIR Connect (2024)
**DOI:** [10.3233/FC-240002](https://doi.org/10.3233/FC-240002)

## Content

EcoPortal is a repository for ecology-specific semantic artefacts. It recently underwent significant updates to improve its functionalities and FAIRness. This document outlines the features of the new release, along with a Semantic Interoperability Profile.
