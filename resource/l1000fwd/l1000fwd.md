# L1000FWD

L1000FWD (L1000 FireWorks Display) is a web application from the Ma'ayan Laboratory at the Icahn School of Medicine at Mount Sinai. It lays out more than 16,000 drug and small-molecule induced gene expression signatures from the LINCS L1000 project as an interactive map, so that compounds with similar transcriptomic effects cluster together. The tool is meant for exploring mechanisms of action and for suggesting functions for less studied small molecules.

## Data Content

Signatures were computed with the characteristic direction (CD) method from L1000 profiles of human cell lines treated with small molecules. The downloadable set covers 42,809 significant signatures in both the 978 landmark gene space and the full 22,268-probe space, a cosine-similarity adjacency matrix among them, up and down gene sets in GMT and JSON form, and metadata for signatures, drugs, and probes. Per-cell-line t-SNE layouts and kNN graphs are offered for about 20 cell lines. Signature landing pages also show drug attributes such as mechanism of action and clinical phase, and prescription statistics (frequent diagnoses, co-prescribed drugs, age distribution) drawn from Mount Sinai Health System electronic medical records.

## Access

The web application supports signature similarity search with up and down gene sets, returning mimicking and opposing signatures, and a REST API exposes drug search, signature retrieval, gene set queries, and top-50 results. Bulk files are served from the download page. On 2026-10-19 the web application and API pages returned HTTP 503 while the static download files were still served.
