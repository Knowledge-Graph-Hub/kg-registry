  tabular sources (CSV, TSV, JSON, JSONL, Parquet, SQL dumps), resolves entities against

  5.x only after a reviewer approves the bundle. BioCypher adapters are supported
  through the import-kg path. Distributed as a Python package in the micromap-oss
