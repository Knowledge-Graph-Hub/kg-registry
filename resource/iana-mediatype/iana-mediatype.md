# IANA Media Types

The Internet Assigned Numbers Authority (IANA) maintains the registry of media types, also known as MIME types or content types. A media type has a top-level type and a subtype, such as `application/ld+json` or `text/turtle`. Registration procedures are defined in [RFC 6838](https://www.rfc-editor.org/rfc/rfc6838).

## Data

The registry is published as one HTML page, one XML file and one text file, plus one CSV file per top-level type: `application`, `audio`, `font`, `haptics`, `image`, `message`, `model`, `multipart`, `text` and `video`. The `example` top-level type is reserved for documentation and has no CSV. Row counts in the CSV product descriptions were taken on 2026-10-04.
