description: Spreadsheet export of search results (Search_results.xls), produced by
  choosing the "Download Excel file" output format on the search form. Searching the
  full default date range (01/01/1983 to today) with no other filters returns the
  complete listing, about 9 MB and 8,247 records on 2026-10-04, with one row per designation
  and columns for names, designation and approval status, dates, indications, exclusivity,
  and sponsor address. The file is an HTML table served with an Excel content type,
  and it is only returned for a form POST to OOPD_Results.cfm; there is no stable
  direct download URL.
