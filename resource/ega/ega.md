# European Genome-phenome Archive

The European Genome-phenome Archive (EGA) archives and distributes personally identifiable genetic, phenotypic and clinical data from biomedical research. EMBL-EBI and the Centre for Genomic Regulation (CRG) run it jointly. It is an ELIXIR Core Data Resource.

## Access

Data in EGA are released only under controlled access. Each dataset (EGAD accession) is linked to a data access policy (EGAP) and a Data Access Committee (EGAC), which decides on requests. Approved users download files with the PyEGA3 client or the Live Outbox, or view them with the FUSE client and EGA QuickView.

Metadata are public. The Public Metadata API at `https://metadata.ega-archive.org/` returns JSON for studies, datasets, DACs, policies, samples, experiments, runs and analyses.

## Federated EGA

Federated EGA (FEGA) is a network of national nodes, such as those in Canada, Finland, Norway, Poland, Portugal, Spain and Sweden, that keep sensitive data within their own jurisdictions while sharing metadata standards and access processes with the central EGA.

## License

The EGA website follows the EMBL-EBI and CRG terms of use. The data themselves are not openly licensed. Each dataset carries the use conditions set by its policy and DAC.
