# BBMRI-ERIC Directory

The BBMRI-ERIC Directory is a central catalog of European biobanks and their sample and data collections, run by BBMRI-ERIC Common Services for IT. It helps researchers find samples and data, helps biobanks advertise their holdings and services, and lets researchers send access requests to biobanks through the BBMRI-ERIC Negotiator. It is not a sample-level query system: records describe biobanks and collections in aggregate.

Biobanks join through their BBMRI National Node. Collection records carry diagnoses (ICD-10 and Orphanet codes), material types, data categories, sex and age ranges, storage temperatures, quality labels and data use conditions. The data model follows MIABIS (Minimum Information About BIobank data Sharing).

## Access

The Directory runs on MOLGENIS EMX2. Its `ERIC` schema is available through:

- a GraphQL endpoint (`/ERIC/graphql`);
- whole-schema exports as a ZIP of CSV tables (`/ERIC/api/zip`), Turtle (`/ERIC/api/ttl`) and JSON-LD (`/ERIC/api/jsonld`);
- per-table CSV downloads (for example `/ERIC/api/csv/Biobanks` and `/ERIC/api/csv/Collections`).

Reference vocabularies used by the Directory are in a separate `DirectoryOntologies` schema on the same server.

No explicit data license was found on the Directory or its help pages when checked on 2026-10-05. The help page notes that ICD-10 codes are used under the WHO non-commercial research license.
